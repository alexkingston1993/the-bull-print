# The Bull Print — Mass Audience Language Guidelines

## Core Language Rules
1. **Never use "Dalal Street"**: Always use **"Indian market"** or **"the Indian stock market"**.
2. **Never use "Smart Money"**: Always use **"big institutional buyers"**, **"large funds"**, or **"institutional investors"**.
3. **Avoid esoteric finance jargon**: Always replace insider jargon with clear, direct terms that general audiences and retail investors instantly understand:
   - Instead of "FII outflows" -> "foreign investors pulling money out" / "foreign selling"
   - Instead of "Liquidity crunch" -> "cash shortage"
   - Instead of "Arbitrage" -> "price difference trading"
   - Instead of "CapEx" -> "infrastructure spending" / "building costs"
   - Instead of "Hawkish / Dovish" -> "raising rates / cutting rates"
4. **Tone**: Authoritative, investigative, dynamic, and crystal-clear for mass consumption.
